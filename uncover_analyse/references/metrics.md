# 指标语义（只读取当前指标部分）

## Toggle / tgl

目标是完整原生 locator 中具体信号位的具体方向（`0 -> 1` 或 `1 -> 0`）发生一次可计分变化。出现过 1 不是 0→1 的充分证据；初始化、X/Z 处理、计分时间窗口及门控配置需要原始编译/采集证据。`goal` 仅在已知原生方向时标为 exact_transition_goal。

组合输出检查数据与选择控制。寄存器检查事件、复位优先级、使能、更新值、前态和未更新时保持。分析 `always_ff @(posedge clk) if (rst) q<=0; else if(en) q<=d;` 时，保留上升沿、rst 优先、`!rst && en` 更新、其余保持，不能只说 q 依赖 d。阻塞/非阻塞及语句顺序可能影响有效驱动，不把所有赋值简单并起来。

查询同一信号反方向、直接源位、控制点等；各自覆盖不证明联合条件发生。native 输出的 instrumented_bits 是插桩范围，与声明范围不同需要解释。不能自动添加 valid/ready，不能从未覆盖推断没有写入或信号恒定。

## Line / line

以 `npiCovStmtBin` 的完整 trail 为原子身份。同一物理行可有多点，甚至显示名相同；按源码行找到 AST 候选后还需对应原生对象。目标是该 statement bin 执行，不是赋值左值变化。

解释所属过程触发、外围控制、分支优先级、调用及提前退出。赋值执行但新旧值相同仍可覆盖 Line。脚本未对循环、break/return、任务/函数调用做完整符号执行；遇到这些结构时保留执行边界，不能直接跳过它们声称找到精确执行条件。

## Branch / branch

原生 `npiCovBranchBin` 可表示 true/false、case 项或工具定义的其他结果。**不能**把 `01` 直接译为 false 或 true。

先 `native` 读取 branch 对象、bin、原生 branch_terms 的名称和值及顺序。native 的 `goal` 在项值可由原生字符串/整数接口核验时输出 `exact_native_terms`；`-` 保留为未约束/未求值项，不强制为二值。值不明确或 terms 缺失时输出 `bin_decode_required`。只有原生映射明确时才构建结果选择条件。`else if` 包含前序判定未选中；`if` 对 X/Z 的控制语义应保留。`case/casez/casex` 的精确匹配/通配含义和优先级不能替换成统一二值相等。

检查外层可达条件、同一判定其他分支、所属语句，但不能把其他分支覆盖当作目标可达证明。NPI language 对象的控制关系是设计证据，不自动证明其与某个覆盖 bin 一一对应。

## Condition / cond

先取得 `npiCovCondition` 的实际监测表达式，以及 `npiCovConditionBin` 的原生 condition_terms、值和顺序。表达式可能分层嵌套，使用最接近目标 bin 的对象，保留祖先上下文。完整表达式是覆盖事实的组成部分，不按当前 RTL 重新分词替代原生 term。

只使用原生 API 暴露的 term 值；保留 don't-care、未知和值未提供的差别。字符串属性为空时读取原生整数属性，只有 0/1 可构成二值条件，-1 不是 false。bin 名如 `0000` 不保证等同完整真值组合，不预设是 MC/DC、单条件真假或短路计分方式。即使 term 取值清楚，还需证明该表达式在目标上下文被求值。

当前实现透传原生 term 表达式和字符串值，不内置跨版本 bin 编码字典。API 没有给出明确项值/语义时停止组合公式推导，报告原始证据和缺少的工具语义；这属于支持的明确分析边界，不是根因结论。
