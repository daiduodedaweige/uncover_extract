# 模块差异分析

模块差异分析已成为主程序唯一流程。直接运行入口即按模型共享覆盖点描述，顺序保存逐实例原生状态，再生成分组报告；完整空洞从事实库离线导出。旧的候选扫描、selected 主项对照和 all 重复枚举代码已移除。

当前参数和迁移说明见 [使用说明](../README.md)，字段见 [输出格式](输出格式.md)。下文全设计测量来自整合前的高效路径，保留为历史性能证据；本次入口整合的验证另见文末。

```bash
python3 uncover_extract.py \
  --vdb merged0608.vdb --rtl-root rtl \
  --metrics line tgl branch cond \
  --out results/module-differences
```

默认工作盘为系统临时目录，结果目录仍由 `--out` 指定。每实例遍历核对完整目标描述并独立读取状态；模型身份不足时按实例隔离，结构缺失或不同的目标明确记录不可比原因。不会仅凭 checksum 跳过目标核对，也不保留跨遍历的原生子句柄。

## 数据与报告

源码和完整原生定位在模型组内每个目标只保存一次；每个实例用编号关联原生 `covered/coverable/raw_status`。超出 SQLite 有符号整数范围的值以十进制文本无损保存。模型目标按照实际完整定位对齐；不同信号位、方向和原生 bin 不因同名或同行而合并。

原生排除点先过滤，不进入分类、计数、报告或发布的事实库。其余各点分成全体已覆盖、共同未覆盖、展示状态不同和共同特殊状态；不可比为独立属性。全体已覆盖与共同未覆盖只汇总；有差异、特殊状态或不可比情况的点进入明细。单实例与未知身份明确标记，不作为多个实例一致的证据。

`report.md` 解释分类依据，按模型及精确实例状态分布归组；同一组的完整实例路径只列一次，随后列出每个具体覆盖点。源码只链接到文件，行号独立展示。`module_summary.json` 提供模型、实例和源码目录，`difference_patterns.jsonl.gz` 提供分组，`differences.csv` 与 `differences.jsonl.gz` 保存覆盖点对分组的引用。`coverage_facts.sqlite` 保留参与分析的紧凑原始事实，可离线重新导出。

这版使用有界批量 SQLite 状态数组，没有把每个目标简化为覆盖布尔值。对齐成功时不再计算和写入重复目标摘要，也不在比较阶段重新访问 NPI；状态比较保留现有展示口径。输出减少并不意味着跳过必要实例状态读取。

## 主流程整合（0.2.0）

高效路径成为默认且唯一实现，CLI 移除模式开关和旧流程专属选项，批次参数改为 `--batch-size`。原生副本、指纹、测试累计、外部排除、范围外对照、URG 及完整事实离线导出继续保留。manifest 格式版本为 2.0；事实库和分组文件结构保持 1.0。

已删除旧候选库、selected/all 比较器、LRU/快照缓存、按目标反复原生重定位、逐主项报告与候选排除生成/验证代码及其专属基准。没有保留旧流程回退入口。历史结果不重写。

当前回归入口为 `tests/`、`scripts/run_scenarios.py`、`scripts/check_missing_identity.py`；`scripts/check_differences.py` 只读核对两份结果的原始事实和分组输出。验证结果保存于 `validation/unified-main-*`。

本次整合验证：25 项逻辑回归、8 个命令入口帮助/版本检查、11 次原生场景及缺失身份核验通过。单测试、累计测试、范围限定与整合前高效路径的逐条事实及报告一致；批次 1/500、已有排除、三类离线导出及失败不覆盖旧结果均通过。

未指定模式或指标的默认命令在当前工程完成四指标全设计扫描：7,753,570 条实例原子状态、869,276 个共享模型目标、4,968 个差异点、5,220 条报告明细、295 个分组。与整合前结果逐条比较全部事实表、分类、分组、JSON/CSV/Markdown 均一致。四项 URG 精确计数通过，原始 VDB 全文件指纹未变。

本次 worker 总耗时 346.021 秒（5.77 分钟），其中原生扫描/状态保存 311.356 秒，分类 25.541 秒，事实库发布 1.415 秒，报告输出 5.090 秒；峰值 RSS 2.60 GiB。这是一次运行，不据此声称相对原高效路径有额外稳定加速；本次改动的主要收益是默认使用高效路径，并删除旧流程。
